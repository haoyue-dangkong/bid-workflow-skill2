# 功能 5：优化技术标书

## 固定执行链路

```text
原始技术标 Word
→ 第一步_格式化
→ 第二步_内容优化（逐篇审核通过）
→ 第三步_页数调整（最终稿）
```

保留原文件，三阶段分别另存，不相互覆盖。第 2 步只能使用第 1 步输出；第 3 步只能使用第 2 步全部审核通过的文件。用户负责审核和确认，执行者负责自动衔接、检查、渲染和页数统计。

## 第一步：统一文档格式

本阶段只改格式，不改写、增删或调整正文顺序。

- 全文仿宋_GB2312、14 磅、黑色、不加粗；若与当前招标文件明确格式冲突，列出冲突并请用户确认后执行。
- 删除 `#`、空白段落和 `---` 等无有效文字/数字的纯符号段；删除两个中文字符间的异常空格，保留中文与英文、数字、单位之间的正常空格。
- 第一行文章标题居中，其他标题左对齐，正文两端对齐。
- 标题编号统一为“一、”“1.”“1.1”“1.1.1”并应用对应 Word 标题样式。
- 正文首行缩进 2 字符，左右缩进 0，段前段后 0，单倍行距。
- 重新统计页数并逐页渲染，检查裁切、重叠、错位、异常空白页和标题孤行。

完成全部文档的第一步并报告检查结果后，再进入第二步。

## 第二步：逐篇内容优化

1. 按文件名前的数字序号处理，一次只处理一篇。
2. 处理前读取用户对当前文章的意见，并应用前文已确认的通用意见；文章专属意见优先。
3. 阅读全文，先建立“必须保留内容和数字白名单”，再标记可删除、概括或改写的内容。
4. 保持章节结构和上下文，在第 1 步格式基础上另存优化稿。
5. 完成内容、格式、数字和逐页检查后，只交付当前文章。用户明确审核通过后才进入下一篇。

必须保留：项目名称、建设地点、工程范围和必要特征；工程概况中的必要面积、层数和结构；明确开竣工日期、总工期和节点；安全、质量、保修等核心目标；影响实质响应、履约或可行性的要求；用户明确要求保留的内容。无法确认是否属于实质要求时列为待确认，不直接删除。

默认可删除或概括：

- 大量标准编号、年份、法规文号和文件编号；
- 工程量清单中的具体尺寸、规格、数量和工程量；
- 工程概况以外的非必要面积、估算量、设备型号/数量/功率、比例、密集区间和复杂公式；
- 无法确认有效性的精确规定、重复内容、无关展开和过细技术细节。

先建立数字白名单，再扫描其他数字。删除数字会破坏语义时，改写为“按设计文件、现场条件、试验结果或现行有效标准执行”等有边界的定性表述。不能因概括而降低承诺、改变实质要求或新增原文没有的数据。

输出前检查核心承诺、白名单外数字、标准编号、含数字括号、语意衔接、矛盾、空段、异常空格、字体标题格式和当前文章页数。

## 第三步：总页数调整

全部文章审核通过后，汇总实测页数并与用户目标比较。

- “控制到 X 页”等明确表达按精确页数处理。
- 用户说“X 页左右”且未给范围时，按第二版口径默认允许正负 1—5 页，并把实际采用的范围先写入报告；招标文件或用户另有明确范围时从其规定。
- 已在允许范围内时停止，不继续凑页。
- 页数不足：增加有依据的评分响应、项目特点、施工组织、质量安全、履约保障、风险预控、协调管理、验收和资料闭合内容。
- 页数超出：优先删重复、无关展开、过细参数、过多标准依据和不必要数字，保持语意和编号完整。

禁止插入空白页、重复无意义内容、虚假章节或数据；禁止通过缩小字号、压缩行距/页边距或改变既定格式操纵页数；禁止删除工程概况、工期、安全、质量、保修和实质响应。

最终逐页渲染并报告每篇页数、总页数、目标/允许范围、差异、调整位置和未解决问题。第三步输出才是正式最终稿。
